# wiki-nlp-scraper
An interactive Streamlit web application for Wikipedia web scraping (Scrapy &amp; BeautifulSoup), NLP preprocessing, and dynamic word cloud visualization.


# 🌐 Wikipedia NLP & Web Scraping App

Uma aplicação interativa desenvolvida em **Python** e **Streamlit** que realiza extração de dados da Wikipédia via **Scrapy** e **BeautifulSoup**, processa o texto com técnicas de **Processamento de Linguagem Natural (NLP)** e gera visualizações analíticas de frequência de termos e nuvens de palavras dinâmicas.

### 🚀 Tecnologias Utilizadas
- **Interface:** Streamlit
- **Web Scraping:** BeautifulSoup4, Requests, Scrapy
- **Processamento de Texto & NLP:** NLTK
- **Visualização de Dados:** WordCloud, Matplotlib
